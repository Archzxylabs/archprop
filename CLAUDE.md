# ARCHPROP Claude Code Worker Contract

This repository is coordinated by an integration orchestrator. Authoritative
requirements are `PRD.md`, `SYSTEM.md`, and `AGENT.md`; integration authority is
`docs/INTERFACES.md`, `docs/OWNERSHIP.md`, `docs/TASK_BOARD.md`, and
`docs/DECISIONS.md`.

Before editing, identify your assigned card and exclusive files in
`docs/OWNERSHIP.md`. Do not change frozen interfaces, shared/root config,
dependencies, documents, or another worker's files. Do not merge/rebase/reset
shared branches, deploy externally, or handle secrets. Validate your work and
return a concise handoff: task ID, commit, files, actual tests, blockers.
